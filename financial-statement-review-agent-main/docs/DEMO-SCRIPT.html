2. Live script (speak this)

0:00–0:25 · Problem

“Financial statements still need manual review for math accuracy, year-on-year change, and consistency. That is slow and easy to miss. We built an AI-assisted review agent that checks the numbers with rules, explains findings with evidence, and can plug into any system through an API.”

0:25–0:45 · How it works (one sentence architecture)

“Rules own the numbers — totals and Balance Sheet identity. GenAI only writes the review wording from those results. It never invents amounts. The UI is one client; the same review runs over REST for ERP, chat, or batch.”

Point at sidebar Integration block for 2 seconds.

0:45–1:30 · Live run (broken pack)

Click: Company = broken → Run review

“On a broken pack we detect math failure on total assets and a Balance Sheet that does not balance — Assets not equal to Liabilities plus Equity — with expected versus actual evidence.”

Click: Findings tab → scroll to red MATH-TOTAL_ASSETS and CONS-01

Click: YoY variances → Revenue

Click: Observations → read one line → click Useful

“Year-on-year, revenue jumped about forty percent, so we flag it as material. Observations cite the check ids. Reviewer feedback is stored so we can improve wording over time.”

1:30–2:00 · Platform / crack points

“Every run has a trace id. Completion and critical fails are notified — logged now, email or webhook when configured. Health endpoint tells ops if the service is down. Under load we can queue reviews; demo path is sync for speed.”

Optional click: Notifications tab · or browser /health · or Swagger POST /reviews

2:00–2:20 · Close

“We followed BRD → HLD → build with MVC services, tests, and CI. This is assistive review — not a statutory audit opinion — but it cuts review time and leaves an evidence trail. Happy to walk the architecture or the clean pack next.”
