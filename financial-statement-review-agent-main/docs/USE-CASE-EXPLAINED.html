1. The story (one paragraph)

A company already has financial statements prepared — Balance Sheet and Profit & Loss — with amounts filled in (Revenue, expenses, assets, liabilities, equity).

A finance reviewer must check: do totals add up? does the Balance Sheet balance? what changed vs last year? what should we comment?

Our agent does that review automatically using match formulas on the given numbers, then writes short observations with evidence.

We are not: calculating profit from invoices, replacing the accountant, reading PDFs in v1, or giving a statutory audit opinion.

2. Input → Output

INPUT

  • Statement numbers already prepared
  • Balance Sheet + P&L
  • Current year + prior year (2 years)
  • Demo: CSV sample files

OUTPUT

  • Pass / fail on match formulas
  • Balance Sheet identity check
  • Year-on-year variance flags
  • Review comments + evidence

3. Match formulas we validate

Same idea as Excel: child lines must equal the reported total.

Total current assets = Cash + AR + Inventory
Total assets = Total current assets + Fixed assets
Gross profit = Revenue + COGS   (COGS stored as negative)
Assets = Liabilities + Equity   (Balance Sheet must balance)

If reported total ≠ formula result → FAIL with expected vs actual.

4. Small real example (from test data)

Broken pack · 2023 · Total assets check

LineAmount
Cash50,000
AR (Accounts Receivable)45,000
Inventory30,000
Fixed assets225,000
Sum of parts (formula)350,000
Total assets reported on statement351,200

Formula says 350,000. Statement says 351,200. Agent result: MATH-TOTAL_ASSETS · FAIL (expected 350000 · actual 351200).

Also: Liabilities + Equity = 350,000 but Assets reported = 351,200 → CONS-01 · Balance Sheet does not balance.

YoY example: Revenue 100,000 (2022) → 140,000 (2023) = +40% → material variance flag (review note, not a math error).
