Clarification sheet

What is Input? What is Output?

Financial Statement Review Agent — sample test files included

Not PDF upload in this version. We do not upload a PDF for AI to invent Profit & Loss. We feed structured BS + P&L numbers. Rules check them. AI only explains evidence.

INPUT

  • CSV files with Balance Sheet + P&L lines
  • 2 years (current + prior) — correct for YoY
  • Pick company pack in UI (or API JSON)

Folder: data/SAMPLE-TEST-PACK/input/

Example lines: Revenue, COGS, Total assets, Equity…

OUTPUT

  • Pass / fail math checks
  • Balance Sheet identity check
  • Year-on-year variance flags
  • Review observations + evidence
  • run id · trace id · notifications log

Folder: data/SAMPLE-TEST-PACK/output-examples/

Same pack shown in UI tabs / API response

Flow

CSV (2 years) → Validation + YoY rules → Findings → Observations (AI/templates) → Review pack

Two years only? Yes — that is enough and intended. Current year for checks; prior year for comparison. More years can be added later.
